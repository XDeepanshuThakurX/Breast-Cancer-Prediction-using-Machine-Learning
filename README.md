
# 🧠 Breast Cancer Prediction using Machine Learning

This project aims to predict whether a tumor is malignant or benign using supervised machine learning algorithms, leveraging the popular Breast Cancer Wisconsin dataset. It focuses on early diagnosis through classification models to assist healthcare professionals.

## 📁 Project Structure

- `Breast_Cancer_Prediction_test.ipynb`: The main notebook containing EDA, preprocessing, model training, and evaluation.
- `requirements.txt`: Python dependencies needed to run the notebook.
- `README.md`: Project overview and instructions.

## 📊 Dataset

- Source: [UCI Machine Learning Repository – Breast Cancer Wisconsin (Diagnostic) Data Set](https://archive.ics.uci.edu/ml/datasets/Breast+Cancer+Wisconsin+(Diagnostic))
- Features include radius, texture, perimeter, area, smoothness, etc.
- Target: Diagnosis (M = malignant, B = benign)

## 🔧 Technologies Used

- Python 3.x
- Libraries:
  - Pandas
  - NumPy
  - Matplotlib
  - Seaborn
  - Scikit-learn

## 🚀 How to Run

1. Clone this repository:
```bash
git clone https://github.com/XDeepanshuThakurX/breast-cancer-prediction.git
cd breast-cancer-prediction
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Open the notebook:
```bash
jupyter notebook Breast_Cancer_Prediction_test.ipynb
```
